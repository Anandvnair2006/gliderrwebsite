# gliderrwebsite

This is a simplified mockup of the **Gliderr** website, designed with a clean and user-friendly interface.

Features

* **Top Navigation Bar**
  Includes icons for:

  * More options (menu)
  * Messages(glider icon)
  * Profile
  * Notifications

* **Google Calendar Integration**
  Seamlessly connect your Google account to view and manage events directly within the site.

* **To-Do List**
  Allows users to add, edit, and track tasks efficiently.

* **AI Chatbox**
  An interactive assistant to answer queries, provide suggestions, and support your goals.

* **Analytics Chart**
  Visual representation of your goals and their completion status to help you track progress.


Goal

The aim of this project is to create a clean, functional interface that reflects the core features of the Gliderr platform. It focuses on simplicity, ease of use, and productivity.
